# Notify Mod

Серверный мод для Minecraft 1.21.1 (NeoForge), который отправляет периодические мультиязычные сообщения игрокам с поддержкой кликабельных ссылок и команд.

## Возможности

- Создание неограниченного количества типов сообщений
- **Мультиязычность** — отдельные тексты для каждого языка из `supportedLanguages` с автоматическим определением языка клиента и фолбэком
- **Множественные тексты** — для каждого типа и языка можно указать несколько вариантов текста
- **Рандомный выбор** — при каждой отправке выбирается случайный текст из списка с привязанным `clickValues`
- Настройка интервала отправки для каждого типа (`interval > 0` секунд)
- Поддержка цветных сообщений (Minecraft color codes `§`)
- Кликабельные сообщения с поддержкой действий:
  - **URL** — открытие `http://` или `https://` ссылки в браузере
  - **COMMAND** — выполнение команды на сервере
  - **SUGGEST_COMMAND** — подстановка команды в строку чата
- Команды `/notify reload` и `/notify resetlangs` без перезапуска сервера

## Установка

1. Скопируйте `.jar` файл мода в папку `mods` вашего сервера (клиентам мод не обязателен)
2. Запустите сервер — конфиг создастся автоматически в `config/notify_mod-common.toml`
3. Настройте конфиг по вашему желанию и выполните `/notify reload` (или перезапустите сервер)

**Важно:** Мод использует прямое чтение TOML файла в UTF-8 (без `ForgeConfigSpec`), поэтому конфиг не перезаписывается при запуске, а ошибки синтаксиса при `/notify reload` не сбрасывают работающую конфигурацию.

## Команды

### `/notify reload`
Атомарно перечитывает конфигурацию из `config/notify_mod-common.toml` и перезапускает планировщик.
- **Требования:** OP уровень 2 или выше

### `/notify resetlangs`
Очищает кэш языков игроков и немедленно обновляет язык для всех игроков онлайн.
- **Требования:** OP уровень 2 или выше

## Конфигурация

```toml
messageTypes = ["Donate", "Tips", "Rules", "Website"]
supportedLanguages = ["ru", "en"]

[messages]
    [messages.website]
        interval = 600
        clickable = true
        clickType = "URL"
        clickValues = [
            "https://www.example.com",
            "https://www.example.com/news"
        ]

        [messages.website.ru]
            texts = [
                "§b[Сайт] §7Посетите наш сайт: §e§nwww.example.com",
                "§b[Сайт] §7Читайте новости проекта! §e§nНажмите сюда"
            ]

        [messages.website.en]
            texts = [
                "§b[Website] §7Visit our site: §e§nwww.example.com",
                "§b[Website] §7Check out our latest news! §e§nClick here"
            ]
```

### Параметры сообщения

- **interval** — интервал в секундах между отправками (значения `<= 0` отключают тип сообщений)
- **clickable** — кликабельное ли сообщение (`true`/`false`)
- **clickType** — тип действия при клике (`"URL"`, `"COMMAND"`, `"SUGGEST_COMMAND"`)
- **clickValues** — список URL или команд по индексам текстов (общий для всех языков; если вариантов текста больше, чем значений, используется последний элемент)
- **[messages.<type>.<lang>].texts** — список текстов для языка `<lang>`

## Цветовые коды Minecraft

- Цвета: `§0` (черный), `§1` (темно-синий), `§2` (темно-зеленый), `§3` (темно-голубой), `§4` (темно-красный), `§5` (темно-фиолетовый), `§6` (золотой), `§7` (серый), `§8` (темно-серый), `§9` (синий), `§a` (зеленый), `§b` (голубой), `§c` (красный), `§d` (розовый), `§e` (желтый), `§f` (белый)
- Форматирование: `§l` (жирный), `§m` (зачеркнутый), `§n` (подчеркнутый), `§o` (курсив), `§r` (сброс)
